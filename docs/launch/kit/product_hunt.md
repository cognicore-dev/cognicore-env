# Product Hunt

**Name:** CogniCore

**Tagline** (60 characters max): Memory that moves between Claude Code and Codex

**Description** (260 characters max):
Your coding agent forgets everything between sessions. CogniCore saves each session automatically, with no model calls, and resumes it in any agent with a short brief: goal, state, open tasks, decisions and exact values. Local and open source.

**Topics:** Developer Tools, Artificial Intelligence, Open Source, Productivity

**Gallery** (in order):
1. The 30-second Claude Code → Codex demo (`cognicore-demo.mp4`)
2. The benchmark table (CogniCore vs claude-mem)
3. The resume brief as an agent sees it
4. The memory viewer page

**Maker comment:**
I built CogniCore because I was re-explaining my work every time I switched agents or started a new session. It hooks into Claude Code and Codex, saves what was said and decided (with exact IDs, versions and paths), and gives the next session a brief of about 450 tokens. On real sessions it matched claude-mem on follow-through with 2.4–4.1× fewer tokens. The benchmark is open, so please rerun it and tell me where it falls short.
